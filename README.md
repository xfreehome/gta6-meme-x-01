## Files

- `meme.png` — the meme (2048×1152), first picture of the X post.
- `main.ts` — the entry program (Node 22, standard library only, no network).
  It verifies `meme.png`, writes `caption.txt` and `manifest.json`.
- `build_meme.py` — builds `meme.png` from the AI-generated Vice City scene
  plus the official press assets in `assets/` (ghost mark + lockup,
  from https://make.fun/press/).
- `POST.json` — the X post address (filled in after posting).
- `caption.txt` / `manifest.json` — generated by `main.ts`.
